# 学习激励系统

一个专为高中生设计的正向激励工具，通过"挣积分 → 兑奖励"的闭环，将学习成果和良好习惯转化为可量化的收益。

## 适用场景

- 高一学生成绩下滑、科目严重偏科
- 家长希望通过正向激励而非强制管教来帮助孩子建立学习习惯
- 需要手机/电脑跨设备同步使用

## 核心功能

### 1. 打卡任务
- **学习任务**：早睡、背单词、深度学习、错题整理
- **家务劳动**：倒垃圾、洗衣、洗碗、整理房间
- 每日/每周自动重置，完成即得奖励

### 2. 考试目标（阶梯解锁）
| 科目类型 | 满分 | 及格线 | 阶梯间隔 |
|---------|------|--------|---------|
| 语文、数学、英语 | 150 | 90分 | 每10分一档 |
| 物理、化学、生物 | 100 | 60分 | 每10分一档 |

- 达成前一目标后自动解锁下一档
- 奖励从 ¥30 到 ¥500 不等

### 3. 年级排名目标
- 前300名 → 前50名，共5档
- 奖励 ¥300 ~ ¥1000，逐级解锁

### 4. 习惯目标
- 一周早睡5天以上：¥20
- 一周单词打卡5天以上：¥15
- 一个月不透支余额：¥100

### 5. 连击奖励
- 连续3天早睡：+¥10
- 连续3天全勤：+¥15

### 6. 兑换商店
- **娱乐**：游戏时间、短视频、电影
- **实物/现金**：零食基金、提现、书籍、聚餐
- **自定义**：可填写任何想要的东西和金额

### 7. 管理后台
- 管理员密码验证（默认 `1234`）
- 余额调整、任务/目标/商品增删改
- 数据导出/导入、服务器同步

## 快速开始

### 本地使用
直接用浏览器打开 `index.html` 即可，所有数据保存在浏览器本地存储中。

### 部署到 Gitee Pages
1. 将本项目上传到 Gitee 仓库
2. 开启 **Gitee Pages** 服务
3. 获得 `https://用户名.gitee.io/仓库名` 的访问地址
4. 手机、电脑均可访问

### 数据同步
- **手动同步**：管理后台 → 导出数据 → 微信发送 → 另一台设备导入
- **自动同步**：配置服务器地址后自动上传下载

## 技术特点

- 纯前端实现，无需后端即可运行
- 单文件架构，部署简单
- 响应式设计，适配手机和电脑
- localStorage 本地持久化存储
- 可选 Node.js/Express 后端实现多设备实时同步

## 使用建议

1. **先打印制度说明**：让孩子清楚知道每一分是怎么来的
2. **家长把控密码**：考试奖励领取必须家长输入密码验证
3. **循序渐进**：先从每天背单词、早睡做起，小步快跑
4. **定期复盘**：每周日一起看看本周赚了多少钱、完成了多少任务

## 数据安全

- 所有数据保存在浏览器本地，不上传到任何第三方服务器
- 建议定期在管理后台导出数据备份
- 长按"本周统计"标签2秒可清空所有数据（谨慎操作）
